# Client marks

Icons for the compatibility grid on the titles page and the downloads page: OpenPak emulators and the operating systems.
Consoles use the marks in `../consoles`.

## Emulator marks added on 18 October 2026

- `quay.svg`, `marina.svg`, `berth.svg`, `wharf.svg`, `pier.svg`: original
  OpenPak artwork provided by tobagin in Downloads (`<name>-icon.svg`), copied
  unchanged. Embedded copyright: 2026 tobagin; AGPL-3.0-only.
- `azahar.png`, `melonds.png`: user-provided 256px renderings of the respective
  upstream project marks from Downloads/console-emulator-logos-256(2).
  These are the Azahar and melonDS marks, not new OpenPak artwork; original
  project ownership is retained. No source licence was included in that pack.

Harbor's existing SVG matches the supplied harbor-icon.svg byte for byte.
