# Console marks

One mark per console, normalised into a 36x24 slot. The slot is 3:2 because most
of these are wordmarks and a square box shrinks a 6:1 logotype to an illegible
smear; square device marks letterbox inside it. The app ships byte-for-byte
copies in `app/assets/consoles`.

Every console mark is the real logo. Only `generic.svg`, the fallback for a
console with no mark, is drawn here.

## Why every mark ships twice

A brand colour is chosen for print and for the company's own white page, not for
our dark row, and there is no white chip behind a mark any more: it sits directly
on the theme's tile (`--paper`, `--paper-2` or `--raised`). So each mark has a
`-dark.svg`: same art, with any colour that would fade against the dark tile
lifted in lightness with its hue kept. The rule, checked against the hardest tile
of each theme (`#31353d` dark, `#e9ecf0` light):

- a coloured fill needs 4.5:1; a near-neutral (black, grey) needs 7:1 and is
  moved to a plain grey, because small wordmarks at 18 to 24 px need the room
  (black becomes `#c4c4c4` in dark);
- the light file gets the mirror rule, darkening what is below the same bar
  (Wii grey, the Wii U blue, the Xbox 360 greens).

Marks that already pass have an identical `-dark.svg` (the Xbox 360 lockup's
tinted parts, Switch red), which keeps both clients dumb: they append `-dark`
and never ask whether it differs. `scripts/consoles.py` applies the rule; to
re-apply it to the files already here after changing the bar, run `adjust()` over
every `#rrggbb` in each file against its tile.

The website picks with `<picture><source srcset="...-dark.svg"
media="(prefers-color-scheme: dark)">`, no JS. An equipped Rewards theme whose
paper does not follow the system setting (dark paper in light mode, or the
reverse) rewrites that media query when the page is rendered (`markMedia` in
`internal/pages/theme.go`). The app passes `Theme.of(context).brightness` to
`consoleAsset`. A browser that reports no preference gets the light file.

## Regenerating

    scripts/consoles.py <source.svg> <slug> [...]   # writes <slug>.svg and <slug>-dark.svg

Needs `rsvg-convert` and ImageMagick. It measures what the art draws, fits it
to the slot, inlines CSS classes, and applies the contrast rule above against
each theme's tile (`--paper-2`). Older marks were fetched from the Iconify API
or Commons, then flattened: metadata, unreferenced
gradients and namespaced editor attributes stripped (they would be unbound
prefixes once the body is rewrapped), and the art scaled to the box — wordmarks
to its width, device marks to whichever side binds first. Keep `consoleSlug` (Go)
and `consoleAsset` (Dart) in step with the filenames here.
