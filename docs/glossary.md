# Glossary — DE, FR, PT-BR, IT, ES

The website catalogue (`internal/i18n`) and the app's ARB files use these words, so a
player sees the same term on both. Change a term here first, then in both places.

## Voice

| | Address | Notes |
| --- | --- | --- |
| DE | *du* | Sentence case; `E-Mail-Adresse`, not `Email` |
| FR | *vous* | Space before `: ; ? !` (non-breaking where it matters) |
| PT-BR | *você* | Brazilian usage (`arquivo`, `celular`, `tela`) |
| IT | *tu* | |
| ES | *tú* | Neutral Spanish: no *vosotros*, no regional slang |

Plain and direct, like the English: short sentences, no marketing tone, no exclamation
marks. Buttons are verbs in the infinitive (DE/FR/IT/ES/PT-BR alike: `Speichern`,
`Enregistrer`, `Salvar`, `Salva`, `Guardar`).

## Never translated

OpenPak, Switch, Wii, Wii U, DS, 3DS, Nintendo, GitHub, Google Drive, OneDrive, S3, WebDAV,
MinIO, Nextcloud, ownCloud, NAS, AGPL-3.0, PNG, JPEG, HTTP, URL, API, `SW-` codes,
status.openpak.org.
